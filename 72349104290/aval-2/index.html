Título do Artigo

Este é um exemplo de página HTML utilizando as principais tags semânticas: <header>, <nav>, <main>, <article>, <aside> e <footer>.

O uso correto dessas tags ajuda na organização do site e melhora a acessibilidade e o SEO. O conteúdo principal fica dentro de main, enquanto o conteúdo complementar fica dentro de aside.
