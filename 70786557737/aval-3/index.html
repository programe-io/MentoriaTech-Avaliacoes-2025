Sobre este projeto

Projeto fictício para demonstrar marcação HTML — foi incluída uma grande variedade de tags e elementos semânticos, microdados de tempo, figuras, tabelas, formulários e exemplos multimídia para que você possa usar como ponto de partida.

Exemplos de tags usadas
  • <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>
  • <figure>, <figcaption>, <picture>, <source>, <img>
  • <table> com <thead>/<tbody>/<tfoot>
  • <form> com <input>, <select>, <textarea>, <datalist>
  • <audio> e <video> (exemplos comentados abaixo)
  • <progress>, <meter>, <details>, <summary>
  • Textuais: <mark>, <time>, <q>, <blockquote>, <code>, <pre>
