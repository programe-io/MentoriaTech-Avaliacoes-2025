O Layout em Detalhes

Esta é a área do conteúdo principal. Em um layout básico, ela ocupa a maior parte da tela. Ela foi definida com a classe `lg:col-span-2` dentro do grid de 3 colunas, garantindo que ocupe dois terços do espaço em desktops.

No mobile, o layout se adapta automaticamente para uma única coluna (`grid-cols-1`), onde o Conteúdo Principal aparece primeiro, seguido pela Barra Lateral.
