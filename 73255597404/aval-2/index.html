Meu primeiro projeto com HTML e CSS

Por Alex Bruno - Novembro, 2025

Comecei meus estudos em desenvolvimento web e esse foi meu primeiro projeto: criar uma página simples usando HTML e CSS. Foi incrível entender como o código se transforma em algo visual e interativo. Estou animado para aprender mais sobre layouts, responsividade e boas práticas! A programação é mais do que apenas escrever linhas de código para que um computador execute tarefas. É uma disciplina que se entrelaça com a filosofia, a lógica e a própria natureza da resolução de problemas humanos.
