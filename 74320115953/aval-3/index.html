Sobre o Curso

O curso de Desenvolvimento de Sistemas prepara o estudante para atuar em diversas áreas da tecnologia, incluindo programação, banco de dados, redes, análise de sistemas e desenvolvimento de aplicações web e mobile. Durante a formação, o aluno desenvolve habilidades práticas e teóricas para criar sistemas completos, seguros e eficientes, utilizando ferramentas modernas e linguagens de programação amplamente usadas no mercado.

Componentes Curriculares

Lógica de Programação

Introdução à lógica computacional, raciocínio algorítmico e resolução de problemas.

Algoritmos e Programação

Criação de algoritmos estruturados e desenvolvimento em linguagens iniciais como Python ou C.

Desenvolvimento Web

Noções de HTML, CSS e JavaScript para criação de sites e aplicações web.

Banco de Dados

Modelagem de dados, SQL, criação e manipulação de bancos relacionais.

Redes de Computadores

Fundamentos de redes, protocolos, segurança e infraestrutura de comunicação.

Análise e Projeto de Sistemas

Modelagem de sistemas, UML, levantamento de requisitos e arquitetura de software.
