Curso de Desenvolvimento de Sistemas

O curso de Desenvolvimento de Sistemas prepara o aluno para criar, testar e implementar softwares e aplicações. Durante a formação, o estudante aprende lógica de programação, banco de dados, front-end, back-end, integração de APIs, desenvolvimento web e mobile, além de metodologias ágeis usadas na indústria.

Atualizado há 10 minutos

O que você vai aprender?

  • Programação em HTML, CSS e JavaScript
  • Desenvolvimento de interfaces modernas
  • APIs e integração com sistemas
  • Banco de dados SQL e NoSQL
  • React, Node.js e outras tecnologias atuais
