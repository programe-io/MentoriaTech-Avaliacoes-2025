Sobre a Turma

A turma de Desenvolvimento de Sistemas é formada por alunos criativos, dedicados e apaixonados por tecnologia. Exploramos lógica, programação, design, banco de dados e criamos projetos que simulam situações reais do mercado de trabalho.

O que estamos aprendendo

  • HTML, CSS e desenvolvimento web
  • Programação em JavaScript
  • Modelagem e análise de sistemas
  • Banco de dados e lógica de programação

HTML é a linguagem responsável por estruturar páginas da web. Define títulos, textos, imagens e links. É a base onde o CSS estiliza e o JavaScript adiciona interatividade.

há 5 minutos

CSS é responsável por deixar o site bonito. Define cores, fontes, espaçamentos e layouts. Transforma um HTML simples em algo visualmente atraente.

há 10 minutos

JavaScript é a linguagem que dá vida ao site. Botões funcionam, menus se movem e elementos reagem ao usuário graças a ele.
