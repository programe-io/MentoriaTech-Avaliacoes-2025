Introdução

O HTML semântico utiliza tags que descrevem claramente o papel de cada parte da página, facilitando a leitura por pessoas e por mecanismos de busca.

Uso da Tag DIV

Texto Informativo

A tag <div> é utilizada para agrupar conteúdos relacionados, facilitando a organização da página.

Aplicações comuns

Divs são muito usadas em conjunto com CSS e JavaScript para criar layout, espaçamentos e estilos personalizados.

Uso da Tag SPAN

Texto Informativo

A tag <span> é usada para destacar palavras importantes sem quebrar a estrutura do texto.
