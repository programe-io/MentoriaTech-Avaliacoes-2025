Sobre a Turma

A turma de Desenvolvimento de Sistemas é formada por estudantes dedicados, criativos e apaixonados por tecnologia. Aqui, exploramos programação, design, lógica e trabalhamos em projetos que simulam desafios reais do mercado.

O que estamos aprendendo

  • HTML, CSS e desenvolvimento web
  • Programação em JavaScript
  • Modelagem e análise de sistemas
  • Banco de dados e lógica de programação
