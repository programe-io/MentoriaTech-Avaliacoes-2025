O que é Vôlei?

Descrição geral do esporte

O voleibol é um esporte coletivo disputado entre duas equipes, onde o objetivo é fazer a bola tocar no chão do time adversário sem que a equipe adversária consiga devolver. É um jogo dinâmico que exige habilidade, agilidade e trabalho em equipe.

Fundamentos do Vôlei

Principais habilidades técnicas

Os principais fundamentos do vôlei são essenciais para o desenvolvimento do jogo e são praticados por jogadores de todos os níveis. Eles são:

  • Saques: O início de cada ponto, onde o jogador lança a bola para o campo adversário.
  • Toque ou Manchete: Técnica usada para receber e controlar a bola, geralmente usada para passes baixos.
  • Levantar: Passar a bola com as pontas dos dedos para um atacante, preparando o ataque.
  • Ataque: O golpe dado para enviar a bola ao campo adversário com força, buscando o ponto.
  • Bloqueio: A defesa feita na rede para impedir ou diminuir a força do ataque adversário.
  • Defesa: A habilidade de salvar a bola e evitar que ela toque no chão do próprio lado.

Regras básicas

Condições para o jogo

Algumas regras importantes do vôlei incluem:

  • Cada equipe pode tocar a bola até 3 vezes antes de enviá-la para o campo adversário.
  • Não é permitido que um mesmo jogador toque a bola duas vezes consecutivas.
  • O time que ganha o ponto serve para o próximo lance.
  • O jogo é disputado em sets, normalmente de 25 pontos, sendo necessário vencer por pelo menos 2 pontos de diferença.

Curiosidade

O voleibol foi criado em 1895 nos Estados Unidos por William G. Morgan, como uma alternativa de esporte com menos contato físico que o basquete.
