O que é HTML Semântico?

A tag $\text{article}$ é um exemplo de **HTML semântico**. Isso significa que ela não apenas formata o texto, mas também dá **significado** àquele conteúdo, indicando que é uma peça independente de informação.

A organização da página com $\text{header}$, $\text{nav}$, $\text{main}$, $\text{aside}$ e $\text{footer}$ torna o código mais acessível e compreensível tanto para outros desenvolvedores quanto para motores de busca.
