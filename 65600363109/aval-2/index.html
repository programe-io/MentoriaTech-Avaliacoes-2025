Artigo Principal

Este é o conteúdo principal do site. Aqui você pode colocar textos, imagens, notícias ou qualquer tipo de informação principal que o visitante deve ver primeiro.

A imagem acima foi adicionada usando a tag <img>. Ela é usada para exibir imagens na web, e o atributo alt serve para descrever a imagem caso ela não carregue.

Informações Extras

O elemento <aside> serve para colocar conteúdo complementar, como:

  • Links relacionados
  • Publicidade
  • Postagens populares
  • Perfis de redes sociais
